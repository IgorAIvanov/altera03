# `<ui-decimal>` — поле десяткового числа

Аналог `decimalInput.tsx` (React/antd) з проєкту `altera_danet`, переписаний на Lit.
Ключова відмінність: вхід у поле **мишею поводиться так само, як по Tab** — значення
виділяється повністю.

## Поведінка

| Дія | Результат |
|-----|-----------|
| Tab у поле | усе значення виділено |
| Перший клік по полю | усе значення виділено (каретка не ставиться по кліку) |
| Клік у вже активному полі | звична каретка / виділення протягуванням |
| Набір тексту | значення НЕ переформатовується, каретка не стрибає; дозволені `1`, `1.`, `-` |
| Blur | значення нормалізується до `precision` знаків (`decimal.js`) |
| Enter | комміт + повторне виділення (зручно для табличних секцій) |
| Esc | відкат до значення на момент входу у поле |

Кома автоматично перетворюється на крапку; сторонні символи відкидаються.

## Властивості

| Атрибут | Тип | За замовч. | Опис |
|---------|-----|-----------|------|
| `value` | string | `""` | канонічне значення (рядок, щоб не втрачати точність) |
| `precision` | number | `2` | знаків після коми: сума — 2, кількість — 3, курс — 6 |
| `label` | string | `""` | підпис |
| `required` | boolean | `false` | зірочка біля підпису: `?required=${this.isRequired("amount")}` |
| `invalid` | string | `""` | текст помилки: червона рамка + підпис під контролом ([ui-form-validation.md](../../../docs/ui-form-validation.md)) |
| `label-position` | `top`\|`left` | `top` | розташування підпису |
| `placeholder` | string | `""` | |
| `disabled` / `readonly` | boolean | `false` | |
| `allow-negative` | boolean | `false` | дозволити від'ємні значення |
| `empty-as-zero` | boolean | `false` | порожнє поле → `0.00` замість порожнього |
| `size` | `xs`\|`sm`\|`md`\|`lg` | `""` | розмір daisyUI-інпута (`sm` — для табличних секцій) |
| `cell` | boolean | `false` | режим комірки табличної частини — див. нижче |
| `width` | string | `""` | CSS-ширина обгортки, напр. `12rem` |
| `visible` | boolean | `true` | |

## Події

- `value-input` — на кожне натискання, `detail.value` — сирий текст (для live-перерахунку похідних полів);
- `value-changed` — на комміт (blur / Enter), `detail.value` — канонічний рядок (для запису в модель).

## Режим комірки (`cell`)

> Повний контракт табличної частини документа — skill
> [`document-tabular-section`](../../../.github/skills/document-tabular-section/SKILL.md).

У табличних частинах документів контрол має займати `<td>` **цілком** — без відступів
зверху, знизу, справа і зліва. Правило:

```html
<td class="p-0"><ui-decimal cell size="sm" ...></ui-decimal></td>
```

`cell` прибирає рамку, заокруглення й обгортку з підписом, розтягує інпут на
100% ширини та висоти комірки; сітку малює сама таблиця. `<td>` **обов'язково**
має бути `p-0`, інакше залишиться падінг daisyUI-таблиці.

Сам стиль живе не в компоненті, а в контракті `.table-tabular` / `.cell-control`
у [`client/styles/theme.css`](../../styles/theme.css) (перенесено з
`.app-table--tabular-section` в altera_danet). Розмітка:

```html
<table class="table table-sm table-tabular">
  <tr>
    <td class="cell-text">1</td>                          <!-- текст: падінг 0 8px -->
    <td><ui-decimal cell ...></ui-decimal></td>            <!-- контрол: падінг 0 -->
    <td><ui-picker cell ...></ui-picker></td>
  </tr>
</table>
```

Правила контракту: висота рядка 24px, контрол без власної рамки, заокруглень,
тіні й фону, **рамки фокуса в комірці немає взагалі** — межу малює тільки
таблиця (так само в altera_danet).

> **Чому не утилітами Tailwind.** У `theme.css` є свій шар теми
> (`.input`, `.join .join-item`, `.table td`), написаний **поза `@layer`**.
> Безшарові правила перебивають будь-який шар Tailwind незалежно від
> специфічності, тому `p-0`, `border-0`, `rounded-none` у комірці **не
> працюють**. Усе, що має перебити тему, пиши в тому ж файлі нижче за неї.

Той самий атрибут `cell` підтримує [`<ui-picker>`](./ui-picker.md) — контроли в
одному рядку вирівнюються між собою.

## Приклад

```ts
import "@client/ui-kit/components/ui-decimal.ts";

html`
  <ui-decimal
    label=${this.t("invoice.qty")}
    label-position="left"
    .value=${item.qty ?? ""}
    precision="3"
    width="10rem"
    @value-changed=${(e: CustomEvent) => { item.qty = e.detail.value; }}
  ></ui-decimal>
`
```

> Похідні поля (сума рядка, підсумок документа) перераховуй на `value-input`,
> але **не переписуй** поле, яке зараз редагується — нормалізація лише на blur
> і ще раз у складальнику payload перед `save`.
