# `<ui-decimal>` — поле десяткового числа

Аналог `decimalInput.tsx` (React/antd) з проєкту `altera_danet`, переписаний на Lit.
Ключова відмінність: вхід у поле **мишею поводиться так само, як по Tab** — значення
виділяється повністю.

## Поведінка

| Дія | Результат |
|-----|-----------|
| Tab у поле | усе значення виділено |
| Перший клік по полю | усе значення виділено (каретка не ставиться по кліку) |
| Клік у вже активному полі | звична каретка / виділення протягуванням |
| Набір тексту | значення НЕ переформатовується, каретка не стрибає; дозволені `1`, `1.`, `-` |
| Blur | значення нормалізується до `precision` знаків (`decimal.js`) |
| Enter | комміт + повторне виділення (зручно для табличних секцій) |
| Esc | відкат до значення на момент входу у поле |

Кома автоматично перетворюється на крапку; сторонні символи відкидаються.

## Властивості

| Атрибут | Тип | За замовч. | Опис |
|---------|-----|-----------|------|
| `value` | string | `""` | канонічне значення (рядок, щоб не втрачати точність) |
| `precision` | number | `2` | знаків після коми: сума — 2, кількість — 3, курс — 6 |
| `label` | string | `""` | підпис |
| `label-position` | `top`\|`left` | `top` | розташування підпису |
| `placeholder` | string | `""` | |
| `disabled` / `readonly` | boolean | `false` | |
| `allow-negative` | boolean | `false` | дозволити від'ємні значення |
| `empty-as-zero` | boolean | `false` | порожнє поле → `0.00` замість порожнього |
| `size` | `xs`\|`sm`\|`md`\|`lg` | `""` | розмір daisyUI-інпута (`sm` — для табличних секцій) |
| `width` | string | `""` | CSS-ширина обгортки, напр. `12rem` |
| `visible` | boolean | `true` | |

## Події

- `value-input` — на кожне натискання, `detail.value` — сирий текст (для live-перерахунку похідних полів);
- `value-changed` — на комміт (blur / Enter), `detail.value` — канонічний рядок (для запису в модель).

## Приклад

```ts
import "@client/ui-kit/components/ui-decimal.ts";

html`
  <ui-decimal
    label=${this.t("invoice.qty")}
    label-position="left"
    .value=${item.qty ?? ""}
    precision="3"
    width="10rem"
    @value-changed=${(e: CustomEvent) => { item.qty = e.detail.value; }}
  ></ui-decimal>
`
```

> Похідні поля (сума рядка, підсумок документа) перераховуй на `value-input`,
> але **не переписуй** поле, яке зараз редагується — нормалізація лише на blur
> і ще раз у складальнику payload перед `save`.
