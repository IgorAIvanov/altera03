# `<ui-period>` — вибір періоду

Одне поле замість пари «дата з / дата по» для звітів і регістрів. Значення —
пара ISO-дат `dateFrom..dateTo`, **обидві включно** — саме так період приймають
SQL-функції звітів.

Посередині — кнопка з людською назвою періоду: календарний період називається
(«Липень 2026», «III квартал 2026», «2026»), довільний показується парою дат
(«01.07.26 — 15.07.26»). Кнопка відкриває пресети (сьогодні, тиждень, місяць,
квартал, рік — цей і минулий) та два `ui-date` для довільного періоду. Стрілки
`◀ ▶` зсувають період на його ж величину: місяць — місяцем (лютий не з'їдає
днів), довільні N днів — на N днів.

Невалідної пари не буває: редагування однієї межі за іншу підтягує ту другу.

```ts
import "@client/ui-kit/components/ui-period.ts";
import { periodOf } from "@client/shared/period.ts";

// дефолт «поточний місяць» — хелпером, а не ручною арифметикою дат
const month = periodOf("month");
this.$root.$query.dateFrom ||= month.dateFrom;
this.$root.$query.dateTo ||= month.dateTo;

html`
  <ui-period
    .label=${t("period.label")}
    .dateFrom=${q.dateFrom}
    .dateTo=${q.dateTo}
    @period-changed=${(e: CustomEvent<{ dateFrom: string; dateTo: string }>) => {
      q.dateFrom = e.detail.dateFrom;
      q.dateTo = e.detail.dateTo;
    }}
  ></ui-period>
`;
```

## Вибір ОДИНИЦЕЮ — `units`

Питання ставлять не лише відрізком: «закриття за березень», «декларація за
I квартал», «баланс за 2025-й». Пресети цього не давали — усі вісім прив'язані
до сьогодні («цей місяць», «минулий місяць»), тож щоб узяти березень у серпні,
лишалося набрати дві дати руками, тобто рівно той ввід, від якого поле й рятує.

`units` міняє поповер: замість пресетів — смуга одиниць, навігатор `‹ 2026 ›` і
сітка з 12 місяців, 4 кварталів або 12 років.

```html
<!-- лише місяці: смуги вкладок немає — вибір з одного пункту не вибір -->
<ui-period units="month" value="2026-03-01"></ui-period>

<!-- одиниці на вибір, плюс довільний відрізок як окрема вкладка -->
<ui-period units="month,quarter,year,custom"></ui-period>
```

Порядок значущий: він задає порядок вкладок і одиницю за умовчанням. Слова —
`month`, `quarter`, `year`, `custom`; невідоме **пропускається з
попередженням** у консоль, а не мовчки. Дня й тижня тут немає навмисно: сітка
для них — це календар, і він уже є (`<ui-date>`).

**Значення лишається парою.** `value` — початок одиниці (`2026-03-01`); він не
замінює `dateFrom`/`dateTo`, а розгортається в них, тож те саме поле годиться і
звіту, що фільтрує однією датою, і звіту, що фільтрує парою:

```ts
html`
  <ui-period
    units="month"
    .label=${t("fxRevaluation.period")}
    .value=${this.filterValue<string>("period") ?? ""}
    @period-changed=${(e: PeriodEvent) => this.setFilter("period", e.detail.dateFrom)}
  ></ui-period>
`;
```

Значення приводиться до початку одиниці: 17 серпня, покладене в поле місяця,
означає серпень — і прочитається з поля як `2026-08-01`, а не як те, що в нього
поклали. Поза режимом одиниці `value` не діє: розгортати нема чим.

Стрілки `◀ ▶` працюють як і раніше — вони зсувають період на його ж величину, а
в режимі одиниці це саме сусідній місяць, квартал або рік.

## Властивості

| Властивість | Тип | Типово | Опис |
|---|---|---|---|
| `date-from` | string (ISO) | `""` | Початок періоду, включно |
| `date-to` | string (ISO) | `""` | Кінець періоду, включно |
| `label` | string | `""` | Підпис поля |
| `label-position` | `top` \| `left` | `top` | Розташування підпису |
| `format` | string | `DD.MM.YY` | Шаблон дат довільного періоду (підпис і поля вводу) |
| `size` | `xs` \| `sm` \| `md` \| `lg` | `""` | Розмір daisyUI-кнопок |
| `width` | string | `""` | CSS-ширина обгортки |
| `disabled` | boolean | `false` | Блокує зміну |
| `visible` | boolean | `true` | Приховує контрол повністю |
| `units` | string | `""` | Одиниці вибору через кому: `month`, `quarter`, `year`, `custom` |
| `value` | string (ISO) | `""` | Початок одиниці; діє лише разом із `units` |

## Подія

`period-changed` — на кожну зміну (пресет, одиниця, стрілка, редагування межі),
`detail: { dateFrom, dateTo, unit }` (ISO або `""`). `unit` — одиниця, якій
період дорівнює РІВНО (`day` | `week` | `month` | `quarter` | `year`), або
`null` для довільного відрізка; так один обробник годиться обом випадкам.

## Хелпери періодів — `client/shared/period.ts`

Логіка не зашита в компонент і доступна окремо:

- `periodOf(unit, base?)` — календарний період (`day` | `week` | `month` |
  `quarter` | `year`), що містить дату `base` (типово сьогодні);
- `shiftPeriod(p, ±1)` — попередній/наступний період тієї ж величини;
- `periodUnit(p)` — якій одиниці період дорівнює рівно, або `null`;
- `parsePeriodUnits(spec)` — розбір переліку одиниць (`"month,quarter"`);
- `monthNames(style?)` — назви місяців мовою інтерфейсу, з великої літери;
- `periodLabel(p, format?)` — людська підпис мовою інтерфейсу; нею ж варто
  формувати `printSubtitle()` звіту, щоб папір не розходився з екраном.
