# `<ui-image>` — зображення моделі

Одне зображення з попереднім переглядом: логотип, фото, скан. Байти зберігає
підсистема вкладень ([docs/blob-subsystem.md](../../../docs/blob-subsystem.md)),
модель тримає лише id.

```html
<ui-image
  .label=${this.t("organization.logo")}
  .valueId=${item.logoId ?? ""}
  .valueToken=${item.logoToken ?? ""}
  owner-model="organization"
  .ownerId=${item.id ?? ""}
  @value-changed=${(e) => { item.logoId = e.detail.id; item.logoToken = e.detail.token; }}
></ui-image>
```

## Значення — це пара

| що | звідки | чи зберігається |
|---|---|---|
| `value-id` | поле моделі (`logoId`) | так, звичайним `save` |
| `value-token` | конверт відповіді (`logoToken`) | ні — рантайм видає новий у кожній сесії |

Компонент **не зберігає модель**. Він вантажить байти на сервер і повідомляє
новий id подією — покласти його в `$root.item` і записати має форма. Це те саме
правило, що в A2v10: ідентифікатор потрапляє в модель тільки при її збереженні.

## Атрибути

| атрибут | тип | за замовчуванням | опис |
|---|---|---|---|
| `label` | string | `""` | підпис над полем |
| `required` | boolean | `false` | зірочка біля підпису |
| `disabled` | boolean | `false` | |
| `value-id` | string | `""` | id вкладення |
| `value-token` | string | `""` | токен доступу |
| `owner-model` | string | `""` | ключ моделі-власника |
| `owner-id` | string | `""` | id запису-власника |
| `accept` | string | `image/*` | фільтр діалогу вибору |
| `max-size-mb` | number | `10` | перевірка розміру на клієнті (сервер перевіряє незалежно) |
| `size` | number | `128` | сторона прев'ю, px |

## Події

`value-changed` — `{ id, token, name, mime, size }`; при очищенні `id` і
`token` рівні `null`.

## Прив'язка до нового запису

Якщо `owner-id` порожній (форма ще не збережена), вкладення створюється
«сиротою». Щойно `owner-id` з'явиться, компонент прив'яже його сам — тому
форма нового запису не потребує жодного додаткового коду.

## Очищення

Кнопка «Очистити» прибирає посилання з моделі, але **не видаляє байти**:
скасована правка форми не має знищувати файл, на який ще посилаються.
Непотрібні вкладення прибирає `app.attachment_gc`.
